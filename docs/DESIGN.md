# Travel Planner — подорожі з відчуттям

Англійський інтерфейс для відкриття країн, міст та цікавих місць. Журнальна композиція, кремовий фон, оливкові акценти, Manrope та Georgia italic. Кнопки, форми, повідомлення, дати й доступні назви країн відображаються англійською; Geoapify використовує `lang=en`.
Референс напряму: [Awwwards — Web & Interactive](https://www.awwwards.com/websites/web-interactive/); композиція та код власні.

## Сценарій

1. Обери країну: англійська назва, прапор, столиця, валюта та мови з Countries GraphQL.
2. Знайди місто через Geoapify: спочатку видно головний результат із назвою області, решта однойменних населених пунктів розгортається через `Other matches`.
3. Переглянь іменовані пам’ятки, музеї, парки, кав’ярні або ресторани в радіусі 2/5/10 км. Безіменні зелені ділянки не підміняються картками міста.
4. Фото автоматично з’являються на видимих картках. Відкрий місце для опису; координати в картці, деталях і маршруті ведуть у OpenStreetMap.
5. Збережи місце або додай у подорож; залиш нотатку та відміть відвідування.

Гостьові маршрути й збережені місця локальні. Після входу маршрути працюють через JWT API у спільному просторі.
Невизначені збіги Wikipedia позначено як результати пошуку. Фото також завантажуються з пов’язаних Wikidata та іншомовних статей. Резервний пошук точної назви у Wikimedia Commons позначається окремо й містить посилання на файл. Для місць без зображень використано графіку з повідомленням про відсутність фото; координати доступні окремим посиланням.

## Дизайн-система

| Елемент | Значення |
| --- | --- |
| Фон | `#f5f3eb` |
| Текст / головні кнопки | `#283629` |
| Акцент | `#e3edb2` |
| Другорядний текст | `#70756a` |
| Лінії | `#d9dbcf` |
| Поля та картки | `#fffef9` |
| Шрифти | Manrope, Georgia italic |

Адаптивні компоненти, нативні діалоги, Escape, повернення фокуса, підписані поля, повідомлення про помилки, порожні результати, завантаження та повтор запиту. Підтримується `prefers-reduced-motion`.

## Ресурси

- Фото Chicago Theatre: [Unsplash](https://images.unsplash.com/photo-1494522358652-f30e61a60313), [ліцензія](https://unsplash.com/license).
- Manrope: [Google Fonts](https://fonts.google.com/specimen/Manrope), SIL Open Font License. Локальні WOFF2 та `fonts/OFL.txt`.
- Дані країн: [Countries GraphQL](https://github.com/trevorblades/countries).
- Місця: [Geoapify](https://www.geoapify.com/), [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
- Описи й фото: англійська Wikipedia, з резервним пошуком зображень у Wikimedia Commons. У деталях місця немає окремих блоків про джерела фото, авторів і ліцензії. Посилання на джерела фото залишаються на картках; позначка пошукового збігу статті залишається біля опису.

Скріншоти `previews/` створені браузерною перевіркою з тестовими місцями. Інтеграції з живими API окремо перевірено на Львові та Бразилії.
